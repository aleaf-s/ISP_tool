# HSV 调色（V0.4.61）

## 范围

用户入口为“手动调色 → HSV 调色”。模块只提供海思样例格式的 HSV TXT 参数导入/导出，不再提供设备 CLUT、设备数据页、预览来源、旧 HS 模型切换或 JSON 参数入口。内部 RGB 查找表仍用于软件图像预览加速，其他模块和历史格式校验工具未删除。

## 文件保留规则

- 支持当前用户样例的 Hue 24 / Sat 12 / Bri 9 轴定义，以及含 360° 接缝的 2700 条六字段记录。节点存储为 V×H×S=9×25×12；原文件记录顺序原样保存，不要求按内存顺序输出。
- 前三字段是 H/S/V 节点索引。末三字段的前两项按目标 H/S 编辑，表格显示相对轴坐标的 ΔHue/ΔSat。第三字段语义未确认，保持原值；重置也只重置 H/S，不清零未知字段。
- 前缀十字段 RGB 对记录、文件头、轴定义、空白、换行、UTF-8 BOM 和未修改数值的文本全部保留。未编辑导出字节一致；编辑后仅替换发生变化的目标数值 token。
- 新建文件使用同一轴定义和 2700 条记录。修改或新生成的数值使用可往返的 Python 双精度文本；界面小数显示不参与量化。未编辑的 H/S 分量不会因修改同节点另一分量而重算。
- S 轴端点 1.17 不是目标 S 上限；导入允许任意有限 H、非负有限 S 和有限第三字段。手动 ΔHue 编辑限制 ±180°，S=0 节点保护。不支持的轴、重复/缺失索引、非法数值或编码会明确报错，旧图像参数不替换。
- 保存使用同目录临时文件和原子替换，失败不覆盖原文件。只接受界面 .txt 后缀；不将 JSON 改名伪装为 HSV。

## 色轮、表格与编辑

色轮显示原始位置到目标位置的虚线，节点填充目标色；目标 S 大于输入轴端点时显示范围自动适应，不改变数据。表格主色块显示该节点目标 H/S，左侧细条显示原色。节点坐标、原/目标读数及表格偏移来自同一份网格。S>1 的屏幕 RGB 色块会裁切，目标 S 数值仍完整保留。

未取色时顶部显示所选节点原色/目标 H/S；从主图取色后显示原图 5×5 均值与软件草稿效果，定位最近 H/S 节点并滚动表格，编辑层固定为 V=0.5。目标节点展示不等于图像效果；未知第三字段不会被伪装成已计算的图像颜色。

单点、表格、拖动、邻域、粘贴和重置选区以 V=0.5 为编辑基准，编辑完成后将中心层完整 H/S 参数等量覆盖全部 9 个 V 层（包括其他层已有 H/S），不按亮度衰减；重置表恢复全部层 H/S。各层未知第三字段保留，不复制。导入、取色、仅调整倍率或增益以及未编辑导出不覆盖原节点。单元格失焦、切格、Tab 可确认数字，非法输入保留并阻止提交。色轮与表格显示草稿；主图只有点击“应用”才更新。导出 HSV 提交并校验所有文本草稿后保存，不应用主图。恢复上次应用清除本次草稿；每张图独立保存网格、历史和取色状态。

已删除“扩展到其他亮度层”按钮及其衰减/保护规则。全亮度覆盖是本工具按用户要求采用的编辑策略，不代表硬件 CLUT 本身不具备亮度选择性。S=0 仍禁止新建非零编辑，0°/360° 接缝独立保留；整层覆盖可撤销，影响范围叠加也覆盖所有 V。

## CLUT 生效强度（独立 Attr）

右侧提供 Enable 与 `gain_r / gain_g / gain_b` 输入和滑条。合法范围为 0～4095 的整数，默认各 512。[官方 CLUT Attr 文档](https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/80RC3alpha003/apiref/appdevgapi/ispdevapi_0275.html)明确 512 归一化后为 1 倍，增益乘查表调整量后再加回输入。软件采用 `out_c = in_c + (lut_c - in_c) × gain_c / 512`。0 为该通道无调整，256 为半强度，1024 为两倍；Enable 关闭时旁路。此增益不乘绝对 RGB，也不乘 ΔHue/ΔSat。插值前保留超出色域的 LUT 顶点，像素插值后统一裁到 0～1，避免高强度下提前裁切改变实际强度。

输入保留为每图草稿，失焦/回车确认、显式应用才刷新主图，支持撤销/重做及恢复到上次应用；预览、取色草稿目标色和 PNG/TIFF 图像导出使用同一增益。HSV TXT 没有 Attr 字段，**不将 Enable 或增益烘焙进 HSV**，设备端需要另填；重新读文件时默认各 512，界面导入到当前图像则保留当前独立 Attr。参数与网格一样只在会话内保留。

## 图像预览限制

HSV 参数倍率（原“整体强度”）为独立系数，范围 0～2，默认 1；0 取消 H/S 调整，0.5 半强度，2 双倍。作用于全部亮度层的 ΔHue/ΔSat，不修改基础节点数据、亮度坐标或未知第三字段；目标饱和度下限裁切到零。轮盘和表格编辑基础参数，顶部取色目标色、应用图像与导出使用乘系数后的参数。系数可撤销/恢复，输入失焦确认，主图仍须点击应用。TXT 不增加私有字段，而是将系数烘焙进 H/S 目标值；重新导入系数默认为 1，避免重复累乘。默认 1 时保持原有字节级无修改导出规则。

预览仍为已有软件 H/S/V 插值模型，不是海思求解器，也不复现其 Gamma 或前缀 RGB 对约束。RGB 增益采用公开 Attr 公式，但它乘的是软件近似 LUT 的调整量；硬件 CLUT 使用线性 RGB，求解器、模块位置和量化均未校准。已知用户使用 PQ Tools V1.1.45，仅有工具版本无法确定芯片/SDK。全亮度覆盖与增益参数均不代表已验证“海思一致”效果。

未知第三字段非零时仍可显示/编辑 H/S 和导出，但禁止应用图像，明确显示“未应用”和原因；可见调试窗口内弹窗说明。未应用修改不覆盖主图。应用后的预览、细节缩放与图像导出共用参数和处理函数，保留滑动对比及原有无拖动缩放。

文件兼容仅针对提供的样例结构；尚未在海思平台实际回导验收，不宣称全部芯片/SDK 格式或设备画面完全兼容。
