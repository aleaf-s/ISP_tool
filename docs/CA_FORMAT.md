# CA 256 点数据与软件预览（V0.4.56）

## 数据格式

上传的 `Chroma_Adjust_Data_DEC_20260923202822.txt` 有 256 个 0～2047 的十进制整数，X 顺序为 0～255；每行 16 个数，整数右对齐占 10 列，逗号分隔。前 15 行行尾有逗号，最后一行没有。行间是 LF，无文件末尾换行。该样例经本工具加载后直接导出，2830 字节完全一致。无效数量、字符、负数或越界值会拒绝加载；写入采用同目录临时文件和原子替换。

官方 [Huawei `hi_isp_cmos_ca` 文档](https://www.hiascend.com/doc_center/source/en/canncommercial/800/apiref/appdevgapi/ispdevug_0118.html) 将 `y_ratio_lut` 定义为根据亮度 Y 选择的 UV 色度调整增益，长度 256，合法范围 0～2047。不同 SDK 文档存在长度变体；本版以用户上传的 256 值文件为准。TXT 只包含该曲线，不含 ISO 增益或设备配置头。

## 曲线编辑

侧栏根据字体所需宽度布局，纵向不足可滚动；应用/恢复放在固定底部，图表使用实际可用尺寸绘制。双击曲线区域可添加节点，重复 X 会选中已有节点并提示。也可手输 X/Y 点击添加；X 失焦或 Enter 查询该位置的曲线值（不覆盖手动修改过的 Y），Y 失焦确认，输入新的 X 时保留为待添加草稿。可右键节点或选中后按 Delete 删除；端点保护，撤销/重做无记录时禁用。节点数量即时显示，与最终 256 个导出值明确区分。所有曲线编辑只改草稿，显式应用才改图像。

## 海思官方工具指南核验（2026-09-24）

用户提供的 [Hi3403 图像质量调试工具指南：通用曲线](https://docs.hisilicon.com/repos/pegasus/zh-CN/master/图像质量调试工具使用指南/图像质量调试工具使用指南.html#id34) 说明了 X 查询、添加控制点、右键取消控制点和十进制曲线文件。本版据此补充查询/右键交互，并沿用用户样例的十进制形式（不是归一化浮点或十六进制）。指南的通用重置为斜线；本工具明确保留“重置为 1×”，避免把 CA 中性效果和通用曲线初始化混淆。该工具指南未规定 CA 的逐像素计算与硬件舍入，也未指定 PCHIP；本工具的平滑算法与设备仿真仍按下述边界说明。

默认 17 个 X 控制点：0、16、…、240、255，Y=1024。可添加控制点（最多 64 个）并删除非端点。编辑后使用保形三次 Hermite 插值（PCHIP）展开为 256 个整数；该插值连续且不会在相邻控制点的区间外产生过冲。浮点结果使用 round-half-to-even 四舍六入五成双，再检查 0～2047。加载文件后未修改时保留原始 256 值，不对已有硬件曲线重新拟合；首次编辑后由当前控制点重新生成整条曲线。

## 预览边界

软件预览在编码 sRGB 图像上使用 BT.709 系数计算 Y：`Y=0.2126R+0.7152G+0.0722B`。以 `Y×255` 在线性插值后的 256 值曲线查表，按 `gain=table/1024` 缩放相对 Y 的两个色度分量，再转回 RGB 并裁剪到 0～1。固定 ISO 色度增益为 1×；无额外 Gamma 或曝光。默认 1024 常数曲线保持原图；图像导出与预览使用同一函数，显示缩放与 8/16 位量化仍可能不同。

这个模型用于观察按亮度调节色度的趋势。上传文件和公开文档不足以确定目标芯片的 UV 编码范围、Y 量化、ISO 增益、内部舍入、模块位置及硬件裁剪规则，因此不把软件预览称为实机逐像素仿真。TXT 的数字格式已由样例验证；设备实际效果仍需对应型号/SDK 或实机对照。
